#  My Virtual Zoo — Jeu de gestion de zoo en C++

Projet réalisé en binôme dans le cadre de la licence Informatique (L3) à l'Université Lyon 2.  
Jeu de gestion textuel d'un zoo, développé en C++ avec les principes de la programmation orientée objet.

---

## Technologies utilisées

- **C++** — programmation orientée objet
- **Terminal** — interface entièrement textuelle

---

## Fonctionnalités

- Ajouter et supprimer des animaux dans le zoo
- Gérer des soigneurs capables de nourrir et soigner les animaux
- Vendre des tickets aux visiteurs
- Architecture orientée objet (héritage, polymorphisme)

---

## Architecture du projet

Le projet s'articule autour de plusieurs classes :

- `Animal` — classe de base pour tous les animaux
- `Soigneur` — gestion du personnel et des soins
- `Visiteur` — gestion des entrées et tickets
- `Zoo` — classe principale orchestrant toutes les entités
